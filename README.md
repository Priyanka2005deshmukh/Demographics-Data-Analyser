Demographic Data Analyzer 

📊A Python-based data analysis project that processes and analyzes demographic census data using Pandas to extract meaningful statistical insights.  

🚀 Features & AnalysisThe core logic is contained in a single function, calculate_demographic_data(), 
which processes raw data and computes the following metrics:   Race Demographics: Counts the total number of individuals for each race category.   Gender Statistics: Calculates the average age of men.  
Education Breakdown: Computes the percentage of the population holding a Bachelor's degree.   Education vs. Income (> $50K):Percentage of individuals with advanced education (Bachelors, Masters, Doctorate) earning more than $50K.   Percentage of individuals without advanced education earning more than $50K.   Work Hours Analysis:Determines the minimum number of hours worked per week.   Calculates the percentage of high-earners (> $50K) among those who work the minimum hours.   Global & Regional Insights:Identifies the native country with the highest percentage of high-earners and its respective percentage.   Finds the most popular occupation for high-earners (> $50K) in India.   🛠️ Tech StackLanguage: Python   Library: Pandas
